# Безопасность

## Что защищает сеть

- **Изоляция.** У каждого пользователя свой Firebase-проект и свой TURN. Разработчик и другие пользователи не имеют доступа к вашим данным: у них нет ни ключей вашего проекта, ни ID вашей сети.
- **ID сети** — 128 случайных бит. Правила базы не позволяют получить список комнат, поэтому без кода приглашения до сети не добраться даже тому, кто знает ключи проекта.
- **Видео** идёт напрямую между устройствами (WebRTC, шифрование DTLS-SRTP). Через TURN проходит уже зашифрованный поток: сервер его не расшифровывает.
- **Код приглашения на Windows/Linux** хранится зашифрованным средствами ОС (DPAPI, libsecret), на Android — в приватном хранилище приложения. Резервное копирование отключено.
- **Правила базы** проверяют формат и размер всех записей: мусор в неё не записать.
- **Поверхность IPC** Electron-приложений минимальна: страницы не имеют доступа к Node.js, наружу открыт только явный список действий (запись файла, настройки сети). Удалённое выполнение команд на устройстве невозможно.

## Прозрачность агента

Агент сделан так, чтобы его нельзя было незаметно использовать против человека за камерой:

- подключение к сети — только вручную на самом устройстве, с подтверждением права на это;
- постоянная иконка в трее (Windows/Linux) или постоянное уведомление (Android);
- во время просмотра иконка и уведомление меняются, на Windows дополнительно всплывает уведомление, работает системный индикатор камеры;
- настоящие название и иконка приложения;
- отключиться от сети можно в самом агенте.

## Чего архитектура не защищает — честно

- **Код приглашения = доступ ко всей сети.** Утёк код — утекла сеть. Не публикуйте его. Если утёк: создайте новую сеть, подключите устройства заново, а старую комнату удалите в Firebase (Realtime Database → Data → `rooms/<ID>`).
- **Полный доступ к устройству из сети** (админ на ПК, разблокированный телефон) даёт доступ и к сохранённому коду.
- **Записи на ПК** хранятся обычными файлами в `Видео\CamerasController`. Их защищает только ваша учётная запись Windows.
