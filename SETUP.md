# Настройка CamerasController

Инструкция для тех, кто ставит CamerasController впервые. Ничего программировать не нужно, понадобятся только браузер и аккаунт Google. Займёт около 15 минут.

**Что вы сделаете:**

1. Создадите свой бесплатный Firebase-проект: через него ваши устройства находят друг друга.
2. Создадите сеть в клиенте.
3. Подключите камеры кодом приглашения.
4. *(по желанию)* Настроите свой TURN-сервер для мобильного интернета — [docs/TURN.md](docs/TURN.md).

---

## 1. Создайте Firebase-проект

1. Откройте <https://console.firebase.google.com> и войдите в аккаунт Google.
2. **Create a project** (или **Add project**) → введите любое имя, например `my-cameras` → **Continue**.
3. Google Analytics можно выключить, он не нужен → **Create project** → **Continue**.

Тариф остаётся бесплатным (**Spark**), банковская карта не нужна. Для личной сети из десятков камер лимитов Spark хватает с большим запасом: через Firebase идут только короткие служебные сообщения, видео через него не передаётся.

## 2. Включите анонимный вход

Устройства входят в ваш проект анонимно: без почты и паролей.

1. В меню слева: **Build → Authentication** → **Get started**.
2. Вкладка **Sign-in method** → в списке провайдеров выберите **Anonymous**.
3. Включите переключатель **Enable** → **Save**.

## 3. Создайте базу данных и вставьте правила

1. В меню слева: **Build → Realtime Database** → **Create Database**.
2. Выберите регион, ближайший к вам (например, `europe-west1`) → **Next**.
3. Выберите **Start in locked mode** → **Enable**.
4. Откройте вкладку **Rules**, удалите всё, что там написано, и вставьте целиком содержимое файла [`firebase/database.rules.json`](firebase/database.rules.json) из этого репозитория.
5. Нажмите **Publish**.

> Правила разрешают доступ только устройствам, вошедшим в проект, и только к той «комнате», ID которой они знают. Кроме того, они проверяют формат всех данных. Чтение списка всех комнат запрещено.

## 4. Скопируйте конфиг веб-приложения

1. Нажмите на шестерёнку рядом с **Project Overview** → **Project settings**.
2. Прокрутите вниз до **Your apps** → нажмите иконку **`</>`** (Web).
3. Введите любое имя приложения, **Firebase Hosting не включайте** → **Register app**.
4. Появится блок кода с `const firebaseConfig = { … }`. Скопируйте его целиком, от `const` до `};`.

   Найти его снова можно здесь: **Project settings → Your apps → SDK setup and configuration → Config**.

Проверьте, что в конфиге есть строка `databaseURL`. Если её нет, значит, приложение зарегистрировали до создания базы: обновите страницу **Project settings** и скопируйте конфиг снова.

> Эти значения — не пароль (так Firebase устроен для любого веб-приложения). Но вместе с ID сети они и есть ваш код приглашения, поэтому не публикуйте их.

## 5. Создайте сеть в клиенте

**Windows:** скачайте `CamerasController-Setup-*.exe` из [Releases](../../releases/latest) и установите.
**Android:** скачайте `camerascontroller-client.apk` и установите. Android попросит разрешить установку из этого источника.

При первом запуске:

1. Выберите **«Создать новую сеть»**.
2. Введите название (видно только вам) и вставьте скопированный `firebaseConfig`.
3. *(по желанию)* Раскройте **TURN-сервер** и заполните его — см. [docs/TURN.md](docs/TURN.md). Здесь же показан **ID будущей сети**: он понадобится, если вы разворачиваете TURN-воркер Cloudflare.
4. Нажмите **«Проверить и создать сеть»**. Приложение само проверит, что анонимный вход включён, база создана и правила вставлены. Если что-то не так, оно подскажет, какой пункт исправить.

После этого появятся **QR-код и код приглашения**. Позже их можно открыть снова: кнопка **«Пригласить»** на панели Windows-клиента или **«СЕТЬ»** в Android-клиенте.

> ⚠️ **Код приглашения — это пароль от всей сети.** Любой, у кого он есть, может смотреть ваши камеры. Пересылайте его только себе, например в «Избранное».

## 6. Подключите камеры

### Windows

1. Скачайте `CamerasController-Agent-*-portable.exe` и запустите. Установка и права администратора не нужны.
2. При первом запуске может появиться окно «Windows защитила ваш компьютер» (приложение не подписано сертификатом): **Подробнее → Выполнить в любом случае**.
3. Вставьте код приглашения, проверьте имя устройства, отметьте согласие → **«Подключить»**.

Агент живёт в области уведомлений (у часов). Во время просмотра значок краснеет и появляется уведомление. Через меню значка можно отключить автозапуск, отключиться от сети или закрыть агент.

### Linux

1. Скачайте `CamerasController-Agent-*.AppImage`.
2. Сделайте файл исполняемым: `chmod +x CamerasController-Agent-*.AppImage` (или в файловом менеджере: Свойства → «Разрешить запуск как программы»).
3. Запустите и подключитесь так же, как на Windows.

### Android

1. Установите `camerascontroller-agent.apk`.
2. **«Сканировать QR»** → наведите камеру на QR в клиенте (или вставьте код вручную).
3. Отметьте согласие → **«Подключить»**.
4. Разрешите камеру и микрофон и отключите оптимизацию батареи для приложения, иначе Android может усыплять агент.

На некоторых оболочках (MIUI, EMUI, ColorOS и др.) дополнительно нужно включить «Автозапуск» или «Без ограничений» для приложения в настройках батареи.

Каждая камера телефона (основная и фронтальная) появляется в клиенте отдельным каналом.

## 7. Смотрите

Камеры появятся в списке клиента сами. Нажмите на камеру, чтобы открыть канал. Что умеет клиент:

- несколько каналов одновременно (раскладка «дуга» или «сетка»);
- запись: на Windows файлы сохраняются в `Видео\CamerasController`;
- обратная связь: кнопка микрофона передаёт ваш голос на динамик камеры;
- ⚙ у камеры — разрешение и FPS для этого устройства.

## Частые проблемы

| Симптом | Что сделать |
|---|---|
| «Не включён анонимный вход» | Шаг 2 |
| «База отклонила запрос» | Шаг 3, пункты 4–5: правила не вставлены или не опубликованы |
| «Нет доступа к Realtime Database» | Проверьте `databaseURL` в конфиге (шаг 4) |
| Камера в списке, но видео не идёт / «подключение…» бесконечно | Устройства в разных сетях без прямой связи — настройте TURN: [docs/TURN.md](docs/TURN.md) |
| На телефоне агент пропадает через какое-то время | Отключите оптимизацию батареи и включите автозапуск в настройках оболочки |
| Потеряли устройство с кодом | Создайте новую сеть и подключите устройства заново. Старую «комнату» можно удалить в Firebase: Realtime Database → Data → `rooms` → нужный ID → удалить |

## Несколько сетей и смена сети

Одно устройство состоит в одной сети. Чтобы перейти в другую, отключитесь от текущей: в клиенте «Пригласить» → «Отключить это устройство от сети», в агенте — через меню трея или кнопку в приложении. Затем подключитесь новым кодом.
